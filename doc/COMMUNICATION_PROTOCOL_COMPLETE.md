# ESP32S3-TFT-BS 完整通讯协议文档

## 📋 概述
ESP32S3-TFT-BS系统是一个集成多功能控制的智能设备，支持：
- **WS2812灯带控制**：4通道智能灯效控制系统
- **电池管理**：智能电量显示和充电状态管理
- **LCD显示控制**：高分辨率TFT屏幕显示管理
- **电压控制**：24V电池系统的精确电压管理

所有功能均通过统一的JSON协议控制，支持串口和网络通讯。

## 🔌 硬件规格

### WS2812灯带系统
- **通道配置**:
  - 通道0: GPIO 18
  - 通道1: GPIO 19  
  - 通道2: GPIO 20
  - 通道3: GPIO 21
- **LED支持**：每通道最多300个LED（动态可配置）
- **特殊功能**：支持电量显示、充电动画、低电量警示

### LCD显示系统
- **分辨率**：428×142像素（横屏模式）
- **颜色深度**：RGB565
- **坐标系统**：原点(0,0)位于左上角
- **显示内容**：电量、电压、充电状态

### 电源管理系统
- **电池类型**：24V锂电池系统
- **电压范围**：18.0V - 29.4V
- **充电检测**：自动充电状态识别
- **电量计算**：基于电压的智能电量估算

## 📡 通讯协议

### 1. 基础通讯格式

#### JSON命令格式（推荐）
所有控制命令使用JSON格式，系统支持智能JSON检测：

```json
{"channel": 0, "mode": 1, "color": {"r": 255, "g": 0, "b": 0}}
```

#### 前缀格式（兼容）
```
JSON:{"channel": 0, "mode": 1}
```

#### 智能检测机制
- 自动检测以 `{` 开头的JSON命令
- 完整JSON对象检测（大括号匹配）
- 支持嵌套JSON结构
- **无需手动添加终止符**

### 2. 通讯方式
- **串口通讯**：115200波特率，8N1
- **网络通讯**：WiFi热点模式，HTTP接口
- **实时响应**：命令执行后立即返回状态

## 🎨 WS2812灯带控制

### 基础控制命令

#### 2.1 通道选择
```json
{"channel": 0}  // 单通道控制 (0-3)
{"channel": 255}  // 广播控制所有通道
```

#### 2.2 显示模式设置
```json
{
    "channel": 0,
    "mode": 1  // 0:关闭 1:静态颜色 2:呼吸灯 3:跑马灯 4:彩虹 5:波浪 6:闪烁 7:自动循环 8:电量显示
}
```

**模式详细说明**：
- `0` - **关闭模式**：所有LED熄灭
- `1` - **静态颜色**：显示指定的单一颜色
- `2` - **呼吸灯**：柔和的亮度渐变效果
- `3` - **跑马灯**：LED逐个点亮的流水效果
- `4` - **彩虹模式**：循环显示彩虹色谱
- `5` - **波浪效果**：波浪形的颜色流动
- `6` - **闪烁模式**：快速闪烁效果
- `7` - **自动循环**：自动切换多种效果
- `8` - **电量显示**：显示电池电量状态

#### 2.3 颜色控制
```json
{
    "channel": 0,
    "color": {
        "r": 255,  // 红色分量 (0-255)
        "g": 128,  // 绿色分量 (0-255) 
        "b": 64    // 蓝色分量 (0-255)
    }
}
```

#### 2.4 亮度控制
```json
{
    "channel": 0,
    "brightness": 180  // 亮度值 (0-255)
}
```

#### 2.5 速度控制
```json
{
    "channel": 0,
    "speed": 150  // 速度值 (1-10000ms)
}
```

#### 2.6 LED数量配置
```json
{
    "channel": 0,
    "led_count": 60  // LED数量 (1-300)
}
```

#### 2.7 通道启用/禁用
```json
{
    "channel": 0,
    "enabled": true  // true启用 false禁用
}
```

### 高级功能

#### 2.8 自动循环配置
```json
{
    "channel": 0,
    "cycle_duration": 8000  // 每个效果持续时间(ms) (1000-60000)
}
```

#### 2.9 组合命令示例
```json
{
    "channel": 0,
    "mode": 1,
    "color": {"r": 255, "g": 0, "b": 0},
    "brightness": 200,
    "speed": 100
}
```

## 🔋 电池电量显示系统

### 3.1 电量显示配置

#### 简化配置（推荐）
```json
{
    "battery_channel": 0  // 指定通道0显示电量
}
```

```json
{
    "battery_channel": 255  // 禁用电量显示
}
```

#### 详细配置（高级用户）
```json
{
    "battery_display": {
        "channel": 0,                    // 显示通道 (0-3或255禁用)
        "show_charging_effect": true,    // 充电动画效果
        "background_brightness": 20      // 背景亮度 (0-255)
    }
}
```

### 3.2 电量状态更新

#### LCD兼容格式（推荐）
```json
{
    "voltage": 24.5,     // 电池电压 (V)
    "battery": 75,       // 电量百分比 (0-100)
    "charging": true     // 充电状态
}
```

#### 传统格式（兼容）
```json
{
    "battery_status": {
        "percentage": 75,    // 电量百分比 (0-100)
        "charging": true     // 充电状态
    }
}
```

### 3.3 电量显示效果

#### 正常电量显示（30%-100%）
- **静态模式**：绿色呼吸灯效果
- **充电模式**：绿色跑马灯动画
- **LED分布**：按电量百分比点亮对应数量的LED

#### 低电量警示（0%-30%）
- **静态模式**：红色呼吸灯效果
- **充电模式**：红色跑马灯动画
- **警示功能**：提醒用户及时充电

#### 背景显示
- 未显示电量的LED显示低亮度白色背景
- 背景亮度可通过 `background_brightness` 调节

## ⚡ 电压控制系统

### 4.1 电压设置

#### 外部电压控制
```json
{
    "voltage": 24.5  // 设置电压值 (18.0V-29.4V)
}
```

#### 自动电压模式
```json
{
    "auto_voltage": true  // 恢复自动电压检测
}
```

### 4.2 组合控制命令

#### 完整电池状态设置
```json
{
    "voltage": 24.8,      // 电压值
    "battery": 85,        // 电量百分比
    "charging": false     // 充电状态
}
```

### 4.3 电压范围说明

| 电压范围 | 电量状态 | 显示效果 |
|---------|---------|---------|
| 18.0V-21.0V | 低电量 (0-30%) | 红色警示 |
| 21.0V-25.2V | 正常电量 (30-80%) | 绿色显示 |
| 25.2V-29.4V | 高电量 (80-100%) | 绿色显示 |

## 🌐 Web服务接口

### 5.1 HTTP接口

#### 基础URL
```
http://192.168.4.1/  // 设备默认IP地址
```

#### 控制接口
```
POST /control
Content-Type: application/json

{
    "channel": 0,
    "mode": 1,
    "color": {"r": 255, "g": 0, "b": 0}
}
```

#### 状态查询接口
```
GET /status
```

返回示例：
```json
{
    "battery_percentage": 75,
    "is_charging": true,
    "voltage": 24.5,
    "channels": [
        {
            "id": 0,
            "enabled": true,
            "mode": 8,
            "led_count": 60
        }
    ]
}
```

### 5.2 WebSocket接口（实时通讯）
```
ws://192.168.4.1/ws
```

支持双向实时通讯，可接收设备状态变化推送。

系统会返回详细的错误信息：

```json
{
    "error": "Invalid channel ID",
    "code": 400,
    "details": "Channel must be 0-3 or 255 for broadcast"
}
```

### 7.3 配置持久化
- 所有配置自动保存到NVS存储
- 系统重启后自动恢复上次配置
- 支持手动保存/加载配置
