# ESP32S3 WS2812 灯光控制系统

这是一个基于ESP32S3的WS2812多通道灯光控制系统，支持通过Web界面进行控制。

## 新增功能

### HTTP网页控制

1. **WiFi AP模式**
   - SSID: `ESP32_LightControl`
   - 密码: `12345678`
   - IP地址: `192.168.4.1`

2. **Web界面功能**
   - 广播控制：同时控制所有4个通道
   - 单通道控制：独立控制每个通道
   - 实时预览：颜色和亮度实时预览
   - 快速预设：一键设置常用模式

3. **支持的灯光效果**
   - 关闭
   - 静态颜色
   - 彩虹效果
   - 呼吸灯
   - 跑马灯
   - 闪烁效果
   - 波浪效果
   - 自动循环

## 使用方法

1. 烧录固件到ESP32S3
2. 连接手机或电脑WiFi到 `ESP32_LightControl`，密码 `12345678`
3. 打开浏览器访问 `http://192.168.4.1`
4. 使用Web界面控制灯光效果

## API接口

全部接口均以 `/api/` 为前缀。

### 灯光控制接口
- `POST /api/control` — WS2812 通道/模式/颜色/亮度控制
- `GET  /api/status` — 查询全局状态 (可附加 `?channel=0` 参数)

示例：
```json
{
  "channel": 0,        // 0-3为单通道，255为广播
  "mode": 1,           // 灯光模式
  "color": { "r": 255, "g": 0, "b": 0 },
  "brightness": 128,   // 亮度 0-255
  "speed": 100         // 效果速度（毫秒）
}
```

### 电池接口
- `GET  /api/battery/status` — 读取电压/电量/充电状态与 RS485 详细数据
- `POST /api/battery/control` — 设置外部电池参数 (电压/电量/充电标志)

### 统一接口
- `POST /api/unified` — 一次提交电压/电量/充电等组合参数，等效于 `battery/control`

### 测试辅助
- `POST /api/test`   — 测试命令
- `POST /api/simple` — 简单回环

## 硬件连接

- 通道1: GPIO18
- 通道2: GPIO19  
- 通道3: GPIO20
- 通道4: GPIO21
- 每通道最多 300 个 LED（运行时可配）

## 电池读取模式 (BOOT 键切换)

板上 BOOT (GPIO0) 按键循环切换以下三种模式，当前模式会持久化到 NVS：

| 模式 | UART1 波特率 | 用途 |
|------|--------------|------|
| `JSON`    | 115200 | 被动接收 JSON 控制命令，不主动发送 |
| `RS485-1` | 9600   | 主动轮询标准电池协议 (DD/77 帧) |
| `RS485-2` | 9600   | 主动轮询客户定制协议 (0xAA 帧头) |

屏幕右上角 `MODE:` 会显示当前模式；切换时固件自动完成波特率切换并刷新串口缓冲。

## 编译说明

确保ESP-IDF环境已正确设置，然后执行：

```bash
idf.py build
idf.py flash monitor
```

系统将自动下载所需的组件依赖（cJSON、LVGL、LED_STRIP等）。
